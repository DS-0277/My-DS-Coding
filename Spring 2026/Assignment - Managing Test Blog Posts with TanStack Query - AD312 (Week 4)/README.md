**Assignment - Managing Test Blog Posts with TanStack Query - AD312 (Week 4)**


**1. Objective:** In this assignment, you will explore how to manage complex server-state and perform CRUD (Create, Read, Update, Delete) operations using TanStack Query. You will interact with the JSONPlaceholder API to simulate real-world data fetching and mutations within a mobile-first environment. There are 3 objectives: (1) understand how to use TanStack Query to manage API requests for CRUD operations; (2) implement GET, POST, PUT, PATCH, and DELETE methods using query and mutation hooks; (3) master data handling in a React application. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Expo.
