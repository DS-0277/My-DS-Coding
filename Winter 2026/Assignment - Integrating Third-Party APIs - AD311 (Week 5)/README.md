**Assignment: Integrating Third-Party APIs - AD311 (Week 5)**

*1. Objective:* Develop a small web application that in integrates with a third-party API of your choice. This assignment is designed to enhance your skills in API integration, understanding documentation, and creating a functional application based on an API's capabilities.

*2. Solution:* The solution to the problem is addressed in 'temperature-check.js' (and 'temperature-check.html'). This application allows users to check for temperature by typing a name of the city. The temperature given will be in degree Celsius.

*3. Test Cases:* The test cases are divided into 3 normal cases and 3 edge cases. Note: The values in the normal cases will change from time to time. 

    The first normal case: 'Seattle' ==> 'The current temperature of Seattle: 8 degrees Celsius]'
    The second normal case: 'New York' ==> 'The current temperature of New York: -16.4 degrees Celsius]'
    The third normal case: 'Sydney' ==> 'The current temperature of Sydney: 23.1 degrees Celsius]'
    The first edge case: ''  ==> 'Please enter a city name'
    The second edge case: 'abcde' ==> 'City not found'
    The third edge case: '1234567' ==> 'City not found'
