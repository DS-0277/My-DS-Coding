**Assignment - Integrating Patient Records from Two Healthcare Providers - Linked List - AD312 (Week 6)**


**1. Objective:** Develop a software module that can take the heads of two sorted linked lists (representing patient records sorted by SSN from HealthMerge and CarePlus) and merge them into one sorted list. This list should be created by combining the nodes (records) of the first two lists without losing any patient information (if the same patient record appears in both lists, the output should contain both of them). The software must ensure that the merged list is sorted so that healthcare professionals can quickly find patient records by SSN number.
