**1. Projects:** I contributed to a project in AD350 on an e-commerce web application with my team member, Mark. The goal of this project is to build a functional, full-stack store that demonstrates real-world database design and API integration. The project is divided into 6 main phases: (1) Planning & Documentation; (2) React + Vite; (3) PostgreSQL Schema + Supabase; (4) API Testing with Postman; (5) Frontend + Supabase Integration; (6) Testing & Final Showcase. The application allows users to browse a product catalog, filter by categories and price ranges, and view product details all powered by a live PostgreSQL database hosted on Supabase. 

**2. Challenges & Solutions:** There are some challenges in this project. First, it is a little bit of challenge when it comes to integrating the app with the API. To solve this problem, I used Postman to test the API endpoints before connecting them to React frontend. Second, configuring secure accessible data fetchingfrom Supabase was also a struggle and to solve this, I needed to carefully define RLS policies.

**3. Key Learnings:** The course reinforced my understanding about Supabase and how it was used to integrate with React and Vite frontend for building an application. By separating the planning, database design, API testing and frontend into distinct phases, I am able to maintain the clear development path.
