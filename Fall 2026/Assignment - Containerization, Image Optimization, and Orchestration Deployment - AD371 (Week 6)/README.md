# Assignment - Containerization, Image Optimization, and Orchestration Deployment - AD371 (Week 6)

*1. Objective:* Packaging an application into an OCI container image and orchestrating it across a cluster are standard operational tasks for modern software architects. However, when developers rely on AI tools to draft container configurations, LLMs frequently introduce anti-patterns: (a) Creating bloated, single-stage images containing full build tools and compilers; (b) Running processes as the privileged root user; (c) Storing sensitive environment variables directly in Dockerfiles or Pod manifests; (d) Omitting liveness/readiness health probes, which breaks zero-downtime rolling updates. In this assignment, you will: (1) Use an AI tool to generate a functional starter web application, an optimized Dockerfile, and an orchestration manifest (e.g., Docker Compose multi-service deployment or Kubernetes Minikube Deployment/Service manifests); (2) Audit and verify the AI-generated artifacts against container security and performance best practices (multi-stage builds, non-root users, resource constraints, and health probes); (3) Deploy and orchestrate the application to verify scaling, rolling updates, and self-healing; (4) Execute a structured Web Project QA test suite to prove container health and application availability; (5) Submit your GitHub repository, live URL (or cluster access evidence), AI prompt log, and a video walkthrough demonstrating functionality and testing.
