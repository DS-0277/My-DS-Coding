# Streamlit deployment launcher

This short-path folder is the Streamlit Community Cloud entrypoint for the
State-Graph ReAct Agent assignment. It exists because Cloud's dependency
installer cannot process the spaces in the original assignment folder path.

Deploy this file in Streamlit Community Cloud:

`streamlit-deploy-stategraph-react-agent/streamlit_app.py`

The actual assignment source remains unchanged under its course folder.
