**Assignment - Managing Nested State in React - AD312 (Week 2)**


**1. Objective:** Learn to update nested objects in React state using the spread syntax and functional updates to ensure immutability. There are 2 objectives: (1) Create a React application that manages a user profile with nested attributes; (2) Allow users to update profile information, including nested fields, in an immutable manner. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'profile-app' which is located inside another directory named 'nested-state-react'. To run the program, we need to make sure we are located at 'profile-app' by running the command prompt 'cd profile-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'UserProfile.jsx' along with the description of test cases.
