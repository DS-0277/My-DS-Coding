**Assignment - Mastering useEffect with a Responsive Canvas - AD312 (Week 8)**


**1. Objective:** In this assignment, you will use the useEffect hook to synchronize your React application with the browser window's size. You will learn how to initialize an effect, manage its dependencies, and crucially, write a cleanup function to prevent memory leaks. You are tasked with building a Responsive Card component. This component must listen to the browser window's dimensions in real-time, display the current width and height on the screen, and dynamically change its visual layout and background color when transitioning between Mobile and Desktop breakpoints.

**2. Solution:** The solution to the problem is addressed in a directory named 'responsive-card-app' which is located inside another directory named 'mastering-useeffect-responsive-canvas'. To run the program, we need to make sure we are located at 'responsive-card-app' by running the command prompt 'cd responsive-card-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' along with the description of test cases. As an additional note for dependency array code comment, we used an empty dependency array configuration because it only needs it to run once for the listener while the filled one could potentially lead to many issues including infinite loops.
