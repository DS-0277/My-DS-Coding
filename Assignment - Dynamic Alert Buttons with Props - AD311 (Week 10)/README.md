**Assignment -  Dynamic Alert Buttons with Props - AD311 (Week 10)**


**1. Objective:** This assignment extends your previous work with alert buttons to create a versatile, data-driven Toolbar. You will learn how to render multiple components dynamically from an array of data, demonstrating how to read and use props within event handlers in a more scalable way. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.

**2. Solution:** The solution to the problem is addressed in a directory named 'dynamic-toolbar-assignment' which is located inside another directory named 'dynamic-alert-buttons'. To run the program, we need to make sure we are located at 'dynamic-toolbar-assignment' by running the command prompt 'cd dynamic-toolbar-assignment'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main file is named 'App.jsx' along with the description of test cases. Additionally, the components used for building the app are addressed as 'AlertButton.jsx' and 'Toolbar.jsx'. One remarkable note is that the folder named 'node_modules' was not included due to large file size.
