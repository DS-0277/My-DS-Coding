**Assignment - Bridging React with Non React Libraries with Chart Integration - AD312 (Week 8)**


**1. Objective:** You will build a Dynamic Poll Dashboard. The application will feature voting buttons for a poll (e.g., "Favorite JavaScript Framework"). When a user votes, React state updates. Your useEffect hook must intercept this state change and imperatively command an underlying raw Chart.js bar chart to update its visual bars in real-time.

**2. Solution:** The solution to the problem is addressed in a directory named 'poll-dashboard-app' which is located inside another directory named 'bridging-react-non-react-libraries'. To run the program, we need to make sure we are located at 'poll-dashboard-app' by running the command prompt 'cd poll-dasboard-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' along with the description of test cases.
