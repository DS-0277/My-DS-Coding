**Assignment - Converting HTML Profile Card to JSX - AD311 (Week 7)**


**1. Objective:** This assignment aims to provide practical experience in converting standard HTML markup into JSX syntax, which is used in React components. Understanding the differences between HTML and JSX and applying best practices in JSX will be the focus.

**2. Solution:** The solution to the problem is addressed in a directory named 'project-user-profile' which is located inside another directory named 'convert-html-to-jsx'. To run the program, we need to make sure we are located at 'project-user-profile' by running the command prompt 'cd project-user-profile'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm start'. The main file is named 'App.js' along with the test case file known as 'App.test.js'. Additionally, the component used for building the app is addressed as 'UserProfile.js', located in 'src/components/'. One remarkable note is that the folder named 'node_modules' contained in the 'project-user-profile' folder was not included due to large file size.
