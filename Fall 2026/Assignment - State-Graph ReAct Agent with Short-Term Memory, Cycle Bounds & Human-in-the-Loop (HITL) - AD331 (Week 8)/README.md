# Assignment - State-Graph ReAct Agent with Short-Term Memory, Cycle Bounds & Human-in-the-Loop (HITL) - AD331 (Week 8)

*1. Objective:* Prompt-driven agentic loops that rely on open-ended while True statements present severe production liabilities: they suffer from semantic goal drift, burn tokens in runaway loops, and execute high-consequence side effects without oversight. Production-grade autonomous software demands deterministic state machine runtimes where agent progression, conversational context, and execution side effects are strictly governed by explicit state transitions. In this assignment, you will build an enterprise ReAct agent using an explicit State Graph (such as LangGraph or a custom Directed State Graph engine). Your agent will maintain short-term conversational memory, execute multi-turn problem-solving cycles with hard recursion bounds and duplicate tool-call detection, and implement a Human-in-the-Loop (HITL) approval gate that suspends the graph before executing sensitive or destructive operations (e.g., balance transfers, account cancellations, or production deployments). By completing this assignment, you will: (1) Architect an Explicit State Graph: Construct a directed graph comprising specialized nodes (agent_reasoning, tool_executor, human_approval_gate, error_handler) and conditional edges governed by a typed state schema; (2) Implement Short-Term Conversational Memory & Persistence: Enable conversational checkpointing across turns using an in-memory or embedded store (e.g., MemorySaver / SQLite checkpointer) so the agent preserves context across user turns and after approval pauses; (3) Engineer Loop Protection & Cycle Containment: Implement cycle bounds (max_iterations = 6) and a payload-hashing circuit breaker (SHA-256 fingerprinting of tool names and arguments) to prevent infinite loops on repetitive tool failures; (4) Build a Human-in-the-Loop (HITL) Gate with Graph Interruption: Classify tools into Safe (read-only queries) and Sensitive (financial/destructive mutations). When a sensitive tool is selected, dynamically interrupt the graph, emit an approval ticket to the user, and resume or abort based on the human operator's decision; (5) Practice Human-in-the-Loop AI Engineering: Use an AI coding assistant to scaffold the state graph, audit the code for execution state loss and checkpointing race conditions, run an automated QA test suite, and present your running system via an interactive web interface and video walkthrough.
