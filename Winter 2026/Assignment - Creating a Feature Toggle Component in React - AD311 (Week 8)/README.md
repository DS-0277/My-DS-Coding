**Assignment - Creating a Feature Toggle Component in React - AD311 (Week 8)**


**1. Objective:** In this assignment, you will develop a simple "Feature Toggle" component in React that demonstrates conditional  rendering based on props passed to the component, avoiding the use of state management. This will help you understand  how to control the display of elements in a React component based on external conditions. Please note: while this  assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite. 

**2. Solution:** The solution to the problem is addressed in a directory named 'feature-toggle-demo' which is located inside another directory named 'feature-toggle'. To run the program, we need to make sure we are located at 'feature-toggle-demo' by running the command prompt 'cd feature-toggle-demo'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main file is named 'App.jsx' along with the test case file known as 'FeatureToggle.test.jsx'. Additionally, the component used for building the app is addressed as 'FeatureToggle.jsx'. One remarkable note is that the folder named 'node_modules' contained in the 'feature-toggle' folder was not included due to large file size.
