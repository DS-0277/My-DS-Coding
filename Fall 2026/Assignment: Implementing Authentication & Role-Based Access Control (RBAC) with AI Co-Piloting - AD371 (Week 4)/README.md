# Assignment: Implementing Authentication & Role-Based Access Control (RBAC) with AI Co-Piloting - AD371 (Week 4)

*1. Objective:* Authentication (AuthN) and Authorization (AuthZ) are the gatekeepers of modern software systems. When developers generate security code with AI, language models frequently suggest insecure defaults—such as storing plaintext passwords, using weak hashing algorithms, relying solely on client-side role checks, or misconfiguring JWT validation. In this assignment, you will: (a) Use an AI tool to generate a functional starter application with user authentication (registration/login) and role-based authorization (e.g., User vs. Admin access); (b) Audit and verify the AI-generated code against security industry standards (e.g., bcrypt/Argon2 password hashing, secure session/token management, and server-side route guards); (c) Execute a structured Web Project QA test suite to confirm both positive paths and negative security attack vectors; (d) Deploy and submit your project with a GitHub repository, AI prompt log, live URL (if applicable), and a video walkthrough demonstrating functionality and security testing.
