**Assignment - Building an Interactive Recipe Gallery with React - AD312 (Week 2)**


**1. Objective:** Develop a React application that showcases an interactive recipe gallery. This assignment demonstrates your ability to use React state to manage dynamic content and respond to user actions. There are 2 objectives: (1) Display images from a predefined list and navigate through them using "Next" and "Previous" buttons; (2) Implement boundary checks for index-based navigation. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'gallery-app' which is located inside another directory named 'interactive-recipe-gallery-react'. To run the program, we need to make sure we are located at 'gallery-app' by running the command prompt 'cd gallery-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'Gallery.jsx' along with the description of test cases.
