**Assignment - Fetching Dog Data with TanStack Query - AD312 (Week 4)**


**1. Objective:** In this assignment, you will learn how to use TanStack Query (formerly React Query) to retrieve, cache, and manage asynchronous data from the Dog API. You will explore how to process API responses and display dynamic content effectively within a React application. There are 3 objectives: (1) master data fetching using TanStack Query hooks; (2) handle various request states: isPending, isError, and isSuccess; (3) navigate API documentation to consume multiple endpoints (breeds, facts, and groups). Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'dog-query-app' which is located inside another directory named 'fetch-dog-data-tanstack-query'. To run the program, we need to make sure we are located at 'dog-query-app' by running the command prompt 'cd dog-query-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' along with the description of test cases followed by relevant components namely, BreedDetails.jsx, DogBreeds.jsx, DogFacts.jsx, DogGroups.jsx.
