# Tech Interview Prep - REST vs. SOAP and Distributed Message Queues - AD371 (Week 8)

**1. Objective:** In technical interviews for backend and enterprise integration roles, interviewers routinely test whether candidates understand how distributed systems communicate across organizational and process boundaries. Two classic questions separate candidates quickly: (1) "Can this candidate objectively compare modern RESTful architectures with legacy enterprise SOAP protocols without simply dismissing SOAP as 'old'?"; (2) "Does this candidate understand the operational physics of asynchronous messaging, or do they treat message queues as magical drop-in fixes for slow code?"
