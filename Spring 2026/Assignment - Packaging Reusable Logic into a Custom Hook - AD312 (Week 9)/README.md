**Assignment - Packaging Reusable Logic into a Custom Hook - AD312 (Week 9)**


**1. Objective:** Imagine you are building a simple streaming website. You want to show a compact, easy-to-use mobile layout when users watch on their phones, and a full-sized layout when they are on a laptop. To do this, you need to track the window's width. While you could write this tracking logic directly inside every single component that needs it, that requires writing a lot of duplicate code. Your goal is to build a custom hook called useWindowSize. This hook will act like a reusable package that any component can import to instantly read the browser's current width and height

**2. Solution:** The solution to the problem is addressed in a directory named 'window-size-app' which is located inside another directory named 'packaging-reusable-logic-custom-hook'. To run the program, we need to make sure we are located at 'window-size-app' by running the command prompt 'cd window-size-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component is named 'App.jsx' along with the description of test cases. The relevant file acting as the custom hook is named 'useWindowSize.js'.
