**Assignment -  Custom Alert Buttons in React - AD311 (Week 10)**


**1. Objective:** In this assignment, you will develop a React application featuring a Toolbar component that houses multiple AlertButton components. This project is designed to strengthen your understanding of how to pass data via props (including the special children prop) and how to execute specific logic using event handlers. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite. 

**2. Solution:** The solution to the problem is addressed in a directory named 'alert-button-toolbar' which is located inside another directory named 'custom-alert-buttons'. To run the program, we need to make sure we are located at 'alert-button-toolbar' by running the command prompt 'cd alert-button-toolbar'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main file is named 'App.jsx' along with the description of test cases. Additionally, the components used for building the app are addressed as 'AlertButton.jsx' and 'Toolbar.jsx'. One remarkable note is that the folder named 'node_modules' was not included due to large file size.
