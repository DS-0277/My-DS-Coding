**Assignment - Building a Global Theme and Dark Mode Switcher - AD312 (Week 6)**


**1. Objective:** In modern web development, “Dark Mode” is a standard feature. Implementing it requires a global state that can be accessed by every component—from the background color of the body to the text color of a tiny button. In this assignment, you will build a Global Theme Switcher using the React Context API to manage a “Light” vs “Dark” theme across your entire application. While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite. There are 4 objectives: (1) use createContext to establish a global theme state; (2) create a custom Provider component to manage the toggle logic; (3) apply dynamic CSS classes or inline styles based on the current Context value; (4) persist the user’s preference (Optional).

**2. Solution:** The solution to the problem is addressed in a directory named 'theme-switcher-app' which is located inside another directory named 'building-global-theme-switcher'. To run the program, we need to make sure we are located at 'theme-switcher-app' by running the command prompt 'cd theme-switcher-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' along with the description of test cases followed by relevant components namely, 'ThemeSwitcher.jsx' and 'ThemeContext.jsx'.
