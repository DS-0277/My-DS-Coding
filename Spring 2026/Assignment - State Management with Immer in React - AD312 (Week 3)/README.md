**Assignment - State Management with Immer in React - AD312 (Week 3)**


**1. Objective:** In this assignment, you will learn to manage complex React State using the useImmer hook from the Immer library. This utility facilitates easier and more readable state updates for nested structures by allowing you to work with a "draft" state that tracks changes and handles immutability for you. There are 3 objectives: (1) master complex state management using the useImmer hook; (2) simplify nested state updates by mutating a draft state rather than manually spreading objects; (3) maintain strict state immutability through the Immer library's internal logic. . Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.
