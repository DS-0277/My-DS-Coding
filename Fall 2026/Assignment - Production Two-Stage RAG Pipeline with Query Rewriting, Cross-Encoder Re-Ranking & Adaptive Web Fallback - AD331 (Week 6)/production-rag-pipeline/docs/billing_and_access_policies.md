# Billing and Access Policies

## Access requests

Access should be granted through named identities, approved by the resource owner, and reviewed periodically. Temporary elevated access should expire automatically.

## Cost controls

Tag resources by team and environment, monitor usage against budgets, and set alerts before expected limits are reached. Expensive workloads should have documented owners and retention policies.

## Data handling

Do not place secrets, customer data, or sensitive operational details in public documents or prompts. Retain only the information needed for the task.
