**Assignment - State Management with useImmer Hook - AD312 (Week 3)**


**1. Objective:** In this assignment, you will learn to manage complex, nested React state using the useImmer hook. This tool facilitates easier and more readable state updates by allowing you to "mutate" a proxy state while maintaining the strict immutability required by React. There are 3 objectives: (1) master complex state management using the useImmer hook; (2) simplify updates to deeply nested objects (e.g., contact details and user preferences); (3) maintain clean and maintainable code without the boilerplate of multiple spread operators. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'user-profile-immer' which is located inside another directory named 'state-management-useimmer-hook'. To run the program, we need to make sure we are located at 'user-profile-immer' by running the command prompt 'cd user-profile-immer'. We can check our status by running 'pwd' in the terminal.
