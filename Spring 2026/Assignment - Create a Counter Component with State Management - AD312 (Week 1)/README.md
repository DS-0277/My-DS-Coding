**Assignment - Create a Counter Component with State Management - AD312 (Week 1)**


**1. Objective:** Develop a simple React application that demonstrates the understanding of state management, asynchronous state updates, and the concept of state as a snapshot. There are 2 objectives: (1) Implement state management using the useState Hook; (2) Understand the "Snapshot" concept and how React batches multiple updates. Note: While this assignment can be completed using Vite or Expo, the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'portfolio-app' which is located inside another directory named 'counter-component-state'. To run the program, we need to make sure we are located at 'portfolio-app' by running the command prompt 'cd portfolio-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'Counter.jsx' along with the description of test cases.
