**Assignment - Building a User Registration Form with React Hook Form - AD312 (Week 7)**


**1. Objective:** In this assignment, you will build a highly performant, client-side validated User Registration Form using the industry-standard React Hook Form library. This exercise is designed to teach you how to move away from heavy state re-renders (controlled inputs) toward uncontrolled, ref-based form architectures that optimize performance, isolate validation rendering, and cleanly integrate with schema validation tools.

**2. Solution:** The solution to the problem is addressed in a directory named 'registration-form-app' which is located inside another directory named 'building-user-registration-form-react'. To run the program, we need to make sure we are located at 'registration-form-app' by running the command prompt 'cd registration-form-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' along with the description of test cases.
