**Assignment - Integrating React Hook Form with TanStack Query and Mock REST APIs - AD312 (Week 7)**


**1. Objective:** In this assignment, you will integrate React Hook Form with TanStack Query (React Query) to handle data fetching, caching, and mutations against a local Mock REST API (JSON Server). This architecture represents the industry standard for enterprise React applications, separating form client-state from server-state while eliminating unnecessary network requests and state synchronization bugs.

**2. Solution:** The solution to the problem is addressed in a directory named 'profile-app' which is located inside another directory named 'integrating-react-form-tanstack-rest'. To run the program, we need to make sure we are located at 'profile-app' by running the command prompt 'cd profile-app'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component file is named 'App.jsx' while 'main.jsx' contains the description of test cases. In addition, 'db.json' is another file being used for storing data on the server. (Note: The keywords 'isDirty' and 'isPending' were later added into the codebase)
