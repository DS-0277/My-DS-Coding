# Assignment - Autonomous Tool Calling & MCP Server Integration - AD331 (Week 7)

*1. Objective:* In this assignment, you will build an end-to-end tool-augmented AI assistant backed by the Model Context Protocol (MCP). You will construct an MCP server that exposes three distinct, sandboxed capabilities (a secure read-only SQL query runner, a live third-party weather/geocoding API, and a deterministic math evaluator), connect it to a client application via standard inter-process transport (stdio or Server-Sent Events/SSE), orchestrate multi-turn function-calling loops, and enforce zero-trust security boundaries. By completing this assignment, you will: (1) Develop a modular MCP Server using the official Python SDK (mcp / FastMCP) exposing three production-grade tools: (a) SQL Database Query Runner: Queries an embedded SQLite database (e.g., e-commerce orders, inventory, or financial ledger) with read-only connection guarantees and strict query validation; (b) Third-Party Weather / Geocoding Client: Fetches live real-time conditions using an external REST API (e.g., Open-Meteo, OpenWeather, or WeatherAPI) with parameter normalization and rate-limit handling; (c) Deterministic Mathematical Evaluator: Evaluates expressions using an Abstract Syntax Tree (AST) safe parser without relying on vulnerable eval() or exec() execution; (2) Build an MCP Host Client & Function-Calling Loop that discovers tools dynamically via the protocol, injects standardized tool schemas into an LLM context, executes returned tool invocations, returns results via role="tool" payloads, and handles chained multi-step tool calls; (3) Enforce Zero-Trust Security & Parameter Sanitization: Prevent SQL injection attacks, sandbox the execution runtime, sanitize external API outputs, and enforce execution timeouts; (4) Practice Human-in-the-Loop Engineering: Use an AI coding assistant to draft the MCP server and client loop, audit the generated code for tool-calling hallucinations and security flaws, execute a structured test suite, and present your solution via a web dashboard and video walkthrough.
