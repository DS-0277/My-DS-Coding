**Assignment - Building a Recipe Gallery in React - AD311 (Week 8)**


**1. Objective:** Develop a Recipe Gallery using React to display a curated list of recipes, focusing on rendering static data. This  assignment emphasizes understanding list rendering in React without involving state management or interactivity. Note: This assignment can be completed using Vite or Expo, but the instructions below are specifically tailored for Vite.  

**2. Solution:** The solution to the problem is addressed in a directory named 'recipe-gallery' which is located inside another directory named 'build-recipe-gallery'. To run the program, we need to make sure we are located at 'recipe-gallery' by running the command prompt 'cd recipe-gallery'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main file is named 'App.jsx' along with the test case file known as 'RecipeGallery.test.jsx'. Additionally, the component used for building the app is addressed as 'RecipeGallery.jsx'. One remarkable note is that the folder named 'node_modules' contained in the 'recipe-gallery' folder was not included due to large file size.
