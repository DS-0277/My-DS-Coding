**Assignment - Building an Application Safety Net with Error Boundaries in React - AD312 (Week 10)**


**1. Objective:** Imagine you are building a social media dashboard. One of your components pulls in a live weather widget. Suddenly, the weather server goes down and sends back corrupted data, causing a JavaScript crash inside that single widget. By default in React, if one unhandled error happens anywhere in your component tree, the entire web page goes completely blank. This is a terrible user experience! Your mission in this lab is to build an Error Boundary. Think of it like a digital structural column: if a small room in your house floods, the Error Boundary seals that room off, displays a friendly "Out of Order" sign to the visitor, and keeps the rest of the house completely safe and functional.

**2. Solution:** The solution to the problem is addressed in a directory named 'error-boundary-lab' which is located inside another directory named 'building-application-error-boundaries-react'. To run the program, we need to make sure we are located at 'error-boundary-lab' by running the command prompt 'cd error-boundary-lab'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm run dev'. The main component is named 'App.jsx' along with the description of test cases. The relevant files are named 'BuggyComponent.jsx' and 'ErrorBoundary.jsx'.
