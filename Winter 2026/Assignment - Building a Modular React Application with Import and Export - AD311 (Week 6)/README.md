**Assignment - Building a Modular React Application with Import and Export - AD311 (Week 6)**


**1. Objective:** To gain hands-on experience with component modularity in React by creating a small application that utilizes both default and named imports/exports.

**2. Solution:** The solution to the problem is addressed in a directory named 'react-frameworks'. To run the program, we need to make sure we are located at 'react-modularity-assignment' by running the command prompt 'cd react-modularity-assignment'. We can check our status by running 'pwd' in the terminal. After that, we can run the server by running 'npm start'. The main file is named 'App.js' along with the test case file known as 'App.test.js'. Additionally, the components used for building the app are addressed as 'Header.js', 'Footer.js', 'ContentA', 'ContentB', and 'SharedComponents', located in 'src/components/'. One remarkable note is that the folder named 'node_modules' contained in the 'react-modularity-assignment' folder was not included due to large file size.
