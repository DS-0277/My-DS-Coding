# Assignment - Production Two-Stage RAG Pipeline with Query Rewriting, Cross-Encoder Re-Ranking & Adaptive Web Fallback - AD331 (Week 6)

*1. Objective:* In enterprise AI engineering, a single-stage vector lookup (similarity_search(query, k=4)) is considered an anti-pattern. User queries are frequently ambiguous, conversational, or under-specified; vector bi-encoders suffer from semantic smearing; and static internal knowledge bases go stale or lack coverage for novel queries. In this assignment, you will engineer a production-ready, resilient two-stage Retrieval-Augmented Generation (RAG) pipeline. Your pipeline will implement query transformation (rewriting/expansion), retrieve candidates via a bi-encoder vector store, refine candidates through a cross-encoder re-ranker, dynamically measure retrieval confidence, and execute an automated fallback to live web search (e.g., Tavily, DuckDuckGo, or SerpAPI) when internal documentation confidence drops below a defined threshold. By completing this assignment, you will: (1) Implement Query Transformation: Engineer a module that takes messy, multi-turn conversational user input and reformulates it into an optimized search query using hypothetical document embeddings (HyDE), sub-query decomposition, or contextual query rewriting; (2) Build a Two-Stage Retrieval Pipeline: (a) Stage 1 (Bi-Encoder Dense Retrieval): Retrieve a broad candidate pool (K1=20-30) using an embedded or hosted vector database (e.g., ChromaDB, Qdrant, or FAISS); (b) Stage 2 (Cross-Encoder Re-Ranking): Score and sort candidates using a cross-encoder model (e.g., ms-marco-MiniLM-L-6-v2, bge-reranker-base, or Cohere Rerank), pruning to the top K2=3-5 most relevant chunks; (3) Architect an Adaptive Confidence Gate & Web Search Fallback: Calculate an aggregate retrieval confidence score from cross-encoder logits. If confidence falls below an empirical threshold (e.g., <0.55), dynamically trigger a fallback web search tool, ingest live search results, and synthesize a cited response; (4) Enforce Citation & Grounding Guardrails: Ensure the final generator explicitly attributes assertions to either internal document chunk IDs or external web URLs; (5) Practice Human-in-the-Loop AI Engineering: Use an AI assistant to generate the baseline pipeline, conduct an audit for critical RAG failure modes (e.g., score threshold inversion, prompt injection via web search, context dilution), execute a structured test suite, and present your solution via a deployed web interface and video walkthrough.
