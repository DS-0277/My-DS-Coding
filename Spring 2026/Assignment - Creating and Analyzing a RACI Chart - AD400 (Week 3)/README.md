**Assignment - Creating and Analyzing a RACI Chart - AD400 (Week 3)**


**1. Objective:** This assignment aims to provide practical experience in developing, analyzing, and documenting a RACI (Responsible, Accountable, Consulted, Informed) chart for a project. You will apply the concepts learned and follow a structured process to define roles and responsibilities, identify potential issues, and understand how such a chart integrates into project documentation tools like Confluence.
